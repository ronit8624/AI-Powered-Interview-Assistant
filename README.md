# AI-Powered Interview Assistant

An AI-powered interview assistant designed to help users prepare for technical interviews through interactive interview sessions, AI-generated questions, and personalized feedback.

## Features

- AI-powered interview question generation
- Interactive interview sessions
- Technical interview practice
- AI-based response evaluation
- Personalized feedback
- Separate frontend and backend architecture
- REST API-based communication

## Tech Stack

### Frontend
- React.js
- JavaScript
- HTML
- CSS

### Backend
- Node.js
- Express.js
- REST APIs

### AI
- Generative AI
- AI-powered question generation and response evaluation
